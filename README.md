# Плагины imgusev для Orca — русификатор интерфейса

> 🇬🇧 **English version** → [README.en.md](README.en.md)

Источник плагинов для [Orca](https://github.com/stablyai/orca) — среды разработки агентов (ADE) от Stably AI. Добавьте его один раз — и плагины ставятся в один клик, а обновления Orca предлагает сама.

Главный из них — **русификатор Orca**: [русский языковой пакет](https://github.com/imgusev/orca-plugin-ru), переводящий интерфейс на 98%. Про него подробно — на [странице проекта](https://imgusev.github.io/orca-plugin-ru/).

Речь именно про Orca от Stably AI, а не про экранный диктор GNOME, редактор MSI-пакетов Microsoft Orca или OrcaSlicer — имя у этих программ общее, продукты разные.

## Подключение

1. **Settings → Plugins** — включите систему плагинов
2. **Marketplace sources → Add source**
3. Вставьте адрес:

   ```
   https://github.com/imgusev/orca-plugins.git
   ```

4. На вкладке **All** найдите нужный плагин и нажмите **Install**

## Сколько раз плагины поставили

Orca ставит и обновляет плагин через `git clone`, а сам индекс клонирует ещё и при проверке обновлений, — поэтому установки видны в статистике трафика GitHub. Данные там живут всего 14 дней, так что раз в сутки их снимает [`.github/workflows/traffic.yml`](.github/workflows/traffic.yml) и дописывает в `data/`:

| Файл | Что считает |
|---|---|
| [`data/traffic-marketplace.csv`](data/traffic-marketplace.csv) | добавления этого источника и проверки обновлений |
| [`data/traffic-plugin-ru.csv`](data/traffic-plugin-ru.csv) | установки и обновления русского языкового пакета |

Отличить установку от обновления нельзя — и то и другое выглядит как клон. Вручную: `python3 tools/traffic.py owner/repo data/файл.csv`.

Статистика живёт здесь, а не в репозиториях плагинов: там — содержимое плагина, здесь — всё, что вокруг него. Нужен секрет `TRAFFIC_TOKEN`: fine-grained токен с правом *Administration: read-only* на репозитории, которые считаем. Встроенного `GITHUB_TOKEN` для traffic API не хватает.

## Как это устроено

Файл `orca-marketplace.json` — индекс: он не содержит кода плагинов, только ссылки на их репозитории и точные теги. Orca клонирует плагин из указанного репозитория по закреплённому `ref`, проверяет манифест и показывает разрешения до включения.

Каждая запись закреплена на конкретный тег, а не на ветку: установка воспроизводима, и новая версия появляется только после явного обновления индекса.
